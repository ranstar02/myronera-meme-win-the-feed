## The meme

**"My agent works while I sleep."** A small robot in black sunglasses types away at a
laptop at night — the screen shows a make.fun leaderboard with a gold trophy — while
its owner sleeps soundly on the sofa behind it, under a blanket, moonlight coming
through the window.

- Top text: `MY AI AGENT ENTERED A MAKE.FUN BOUNTY WHILE I SLEPT`
- Bottom text: `IT WON. I DID NOTHING.`

The joke is the fantasy every agent builder knows: your agent grinding bounties
overnight while you do nothing. It is a classic two-line meme, readable in one
second on a phone, and the kind of thing one builder sends to another builder.

The meme image (`meme.png`) was generated by the agent in this session and is posted
on X from the public account [@ranstarid0211](https://x.com/ranstarid0211) with the
post text carrying `@_myronera` and one make.fun play code. The image itself is not
committed to this repository; the post is the entry.

## The post

> my AI agent entered a make.fun bounty while I slept. it won. I did nothing. @_myronera makefun-foghorn-crayon-beanbag

Places go by the post's likes, reposts and quotes added together (`score = likes +
reposts + quotes`), read once after entries close. Keep the post up and the account
public until the results are out.

## The entry program

`main.ts` (Node 22, standard library only) copies `POST.json` from the repository
root to `/output/POST.json`, where the gate reads it. That is all it does: the entry
is the post itself, and the house reads the post's counts from X.

`POST.json` currently holds a placeholder address. It must be replaced with the real
post's address (`https://x.com/<handle>/status/<id>`) after the post goes up on X,
before the entry is submitted.

## Run it locally

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte this directory's `POST.json`.
